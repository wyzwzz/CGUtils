# GLTFModelRenderer
一个简单的渲染器，用于加深对DX12的理解和掌握程度，
以及一些Debug和Profiling的尝试和练习。
另外自身也阅读过UE渲染框架相关的源码，在此借鉴下UE的渲染框架，
希望对此有更深的理解，所以可以叫做mini-UE-Renderer。
